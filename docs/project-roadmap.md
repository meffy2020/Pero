# Pero Project Roadmap

## 지금까지 했음

- 검색 프로토타입 만들었음.
- Spring Boot 검색 API 붙였음.
- Next.js 검색 화면 붙였음.
- 지도 연동했음.
- 검색 근거 문장 반환 붙였음.
- 기본 테스트와 빌드 통과 상태 맞춰둠.

## 주제 방향

- 리뷰 기반 검색에서 메타데이터 + 위치 기반 검색으로 조정했음.
- 발표와 문서 설명은 이 기준으로 맞추면 됨.

## 아직 안 했음

- 데이터 50~100건 확장 안 했음.
- 검색 품질 평가셋 안 만들었음.
- 검색 로그 저장 안 붙였음.
- OpenSearch 전환 안 했음.
- Docker Compose와 배포 문서 정리 안 했음.

## 다음에 해야 함

1. 데이터 확장해야 함.
2. 대표 질의셋 만들어야 함.
3. 검색 로그 저장 붙여야 함.
4. OpenSearch 전환 검토해야 함.
5. 배포/실행 문서 정리해야 함.

## 참고

- 상세 실행/현황은 `docs/development.md` 기준으로 봄.
